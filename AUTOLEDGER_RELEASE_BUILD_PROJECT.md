## Permanent Pro rule
Every future Pro iteration is an UPDATE to the existing Pro product. Existing valid Pro entitlement keys must remain accepted across software updates unless explicitly changed by the product owner. The current permanent entitlement format remains `ALP225R6`.

## Current TEST activation status
The one-PC activation framework is present and tested, but the production activation endpoint at `api.autoledger.co.za` is not yet deployed. R8 TEST therefore allows a valid existing Pro entitlement to continue in migration-pending/test mode until production activation is enabled.
