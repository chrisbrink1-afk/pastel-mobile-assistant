R10.4 CHANGES

1. Guided Walkthrough improvements
- The tutorial remains inside the normal AUTOLEDGER interface.
- The instruction bubble automatically moves away from the control the user must click or edit.
- The actual interactive field, dropdown, checkbox, button or transaction table is highlighted rather than merely a nearby label.
- A four-sided highlight surrounds the required control.
- A gentle animated arrow points toward the required control without covering its click/edit area.
- The walkthrough follows the normal Saved Rule dialog and explains its important fields individually.

2. Saved Rule Priority guidance
- Leave Priority at 100 for normal rules.
- Higher values such as 200 or 300 should only be used when a more-specific rule must take precedence over a broader rule that could also match the same transaction.
- Higher Priority numbers are considered first.

3. Installation / update rule
- If AUTOLEDGER is already installed, use the R10.4 UPDATE installer.
- Use the R10.4 FULL / STANDALONE installer for a clean PC or clean installation.
- R10.4 Update recognises R10.3 plus the supported R6, R8, R9, R10, R10.1 and R10.2 installation lineage.
- Existing AUTOLEDGER local data, settings and Free usage data are preserved by default during an update.
- Existing valid AUTOLEDGER Pro licence data is preserved by default during an update.

4. Installer finish option
- The installer provides a checkbox on the final page allowing AUTOLEDGER to be launched immediately after installation.

5. Uninstall local-data option
- During uninstall, AUTOLEDGER asks whether local data and settings should also be removed.
- Choose No if you want to preserve the local data for a later reinstall or update.

UNSIGNED TEST BUILD NOTICE

This is an unsigned TEST build. Windows may display Unknown Publisher or Microsoft Defender SmartScreen warnings until the AUTOLEDGER SYSTEMS PTY LTD code-signing certificate is issued and applied.

Supported target platform for current testing: Windows 10 x64 and Windows 11 x64.
